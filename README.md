# TM Desenvolvimento Tecnologia

Site institucional da **TM Desenvolvimento Tecnologia** — planilhas prontas, calculadoras, serviços de TI e conteúdo de tecnologia.

🔗 **Site no ar:** [tmdesenvolvimentotecnologia.netlify.app](https://tmdesenvolvimentotecnologia.netlify.app/)

## O que tem no site

- **Início** — apresentação da marca
- **Blog** — artigos sobre planilhas, automação e IA (Claude, ChatGPT, Gemini, Python para iniciantes)
- **Planilhas** — loja com 12 planilhas e calculadoras prontas para compra
- **Serviços** — manutenção de computadores, redes, softwares sob medida, design de campanhas
- **Parceiros** — empresas que já usam as soluções da TM
- **Comunidade** — depoimentos, comentários e newsletter
- **Contato** — formulário, e-mail, Instagram e WhatsApp

Todas as ações de compra, contato e comentário abrem o WhatsApp automaticamente com a mensagem já preenchida — o site não depende de servidor/backend.

## Estrutura de arquivos

```
index.html                     → página principal do site
blog-formulas-sheets.html      → artigo: fórmulas do Google Sheets
blog-ia-rotina.html            → artigo: IA na rotina
blog-fluxo-caixa.html          → artigo: fluxo de caixa
blog-claude-iniciantes.html    → artigo: Claude para iniciantes
blog-python-iniciantes.html    → artigo: Python para iniciantes
blog-chatgpt-dicas.html        → artigo: dicas de ChatGPT
blog-gemini-dicas.html         → artigo: dicas de Gemini
```

Cada arquivo é autocontido (HTML + CSS + JS em um único arquivo), sem dependência de build ou instalação.

## Publicação (deploy)

O site está conectado ao **Netlify** com publicação automática: qualquer alteração enviada (push/commit) para este repositório atualiza o site publicado em poucos segundos, sem precisar de nenhuma ação manual no Netlify.

## Como atualizar o site

1. Edite o arquivo desejado (ou peça a atualização pronta)
2. No GitHub, abra o arquivo → ícone de lápis (**Edit**) → cole o novo conteúdo → **Commit changes**
   - ou use **Add file → Upload files** para substituir vários arquivos de uma vez
3. Aguarde 1–2 minutos e confira o site publicado
